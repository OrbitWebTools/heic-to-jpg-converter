    How to convert HEIC to JPG

    1. Add one or more HEIC or HEIF files with drag and drop or the file picker.
    2. Pick a JPG quality. 90% is a good balance of size and detail.
    3. Download each JPG, or use Download all as ZIP.

    Supported formats and browsers

    Input: .heic and .heif. Output: .jpg. Requires a recent browser with WebAssembly and Web Workers, which current Chrome, Edge, Firefox and Safari generally provide. Not every browser version and device has been tested. Some unusual HEIC variants (for example certain multi-image or very new encodings) may fail to decode. If that happens you will see an error for that file. Metadata such as EXIF is not guaranteed to be kept.

    Frequently asked questions

    What is a HEIC file?

    HEIC is the image format iPhones use by default. It stores photos at smaller sizes than JPG, but many Windows apps, websites and forms don't accept it.

    How do I convert HEIC to JPG?

    Add your files above, choose a quality and download the JPGs. No installation is needed.

    Is this converter free?

    Yes. It is free to use with no account or watermark, but limits apply: up to 50 files, 50 MB per file and 300 MB per session.

    Are my photos uploaded to a server?

    No. Conversion happens in your browser. This site has no backend.

    Can I convert multiple files?

    Yes. Add many files at once (within the limits above) and download them individually or as one ZIP.

    What should I do if a file fails to convert?

    Check the file really is HEIC/HEIF and not a renamed JPG or PNG (some iPhones and browsers already convert photos when you pick them), try converting it alone, or retry in another browser. Very large files can run out of memory on phones, so try fewer files at a time.

    Does it work on mobile devices?

    Yes, on modern mobile browsers. Large batches are slower on phones, so convert in smaller groups.
